# TRPG Frontend

Standalone Vite and React frontend for the TRPG tools that previously lived inside `react-portfolio`.

## Local Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Configure the API URL in `.env`:

```env
VITE_TRPG_API_URL=http://localhost:8000
```

## Commands

```bash
npm run lint
npm run build
```
